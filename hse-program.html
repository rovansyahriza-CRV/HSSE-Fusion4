HSE Program

Target tahunan (per bulan) untuk tiap kegiatan HSSE per project -- lampiran dari HSE Plan project yang bersangkutan. Toggle Use kalau item ini berlaku di project ini, isi target per bulan, dan realisasi otomatis dihitung dari data laporan yang sudah masuk.

HSE Program ini adalah bagian dari HSE Plan project (dokumen kebijakan/organisasi HSE yang lebih luas, dikelola di luar sistem). Item-item di bawah ini generik/sama untuk semua project -- yang berbeda per project cuma toggle Use/N/A dan nilai targetnya.
